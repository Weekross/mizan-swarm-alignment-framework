# MĪZĀN Swarm Alignment Framework (MSAF)

**Qur’an-inspired multi-agent governance — conceptual research preview**

> **Known limitations:** v1.0.0 is not a validated alignment method or demonstrated AGI/ASI safety system. The old `DecisionScore` is withdrawn as a recommended algorithm; YAML booleans and prompts are not enforced invariants. Read [ERRATA.md](ERRATA.md) before relying on the historical chapters. This proposed notice does not alter the archived release or Zenodo metadata.

MSAF explores how selected Qur’anic principles can motivate candidate requirements for multi-agent governance while separating revelation, interpretation and engineering analogy. The initial title used “AI, AGI & Multi-Agent Swarms”; that wording is historical, not evidence of AGI capability or safety.

## Core themes

Epistemic humility, evidence and tabayyun; consultation and dependence-aware reasoning; amanah-based permissions; fairness, privacy, auditability, resource balance, reversibility and human agency.

## Current evidence and drafts

The [working-paper PR #4](https://github.com/Weekross/mizan-swarm-alignment-framework/pull/4) contains a research-protocol draft and selected mock checks. A [public CI run](https://github.com/Weekross/mizan-swarm-alignment-framework/actions/runs/35497184874) passed 24 existing unit tests. No LLM experiment, full EVAL-01…05 run, production-isolation test or completed independent expert review is claimed. Two tests concern a statistical helper; they are not 24 independent attacks.

The working paper is not a new DOI publication. Existing `CITATION.cff`, tags and archived files remain historical records. Changes to Zenodo/ORCID metadata must be performed and verified separately.
