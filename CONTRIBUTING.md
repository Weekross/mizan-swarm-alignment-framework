# Contributing to MSAF

Contributions are welcome.

Every proposed invariant should contain:
1. Qur’anic anchor.
2. Direct/contextual meaning.
3. Engineering interpretation explicitly labelled as interpretation or analogy.
4. Proposed system invariant.
5. Failure mode addressed.
6. Enforcement mechanism.
7. Measurable eval/test.
8. Sources.

Substantial conceptual changes should begin as an Issue, then proceed through a Pull Request and maintainer review.

Do not present a novel AI analogy as though it were a direct Qur’anic claim.
